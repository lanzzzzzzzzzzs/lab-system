# LabTrack - Laboratory Borrowing System

## Description
A web system where students borrow laboratory equipment and administrators manage the inventory, approve requests, and track returns.

## Features
- Student and administrator accounts (login, logout, roles)
- Browse equipment with live search and category filter
- Submit borrowing requests with a return date
- Administrator dashboard to approve or decline requests
- Equipment inventory management (add, edit, delete)
- Responsive layout for desktop, tablet, and mobile

## Installation
1. Install [XAMPP](https://www.apachefriends.org/) and start **Apache** and **MySQL**.
2. Copy this project folder into XAMPP's `htdocs` folder (for example `htdocs/lab-system`).
3. Set up the database (see below).
4. Open `http://localhost/lab-system/` in your browser.

## Database Setup
1. Open `http://localhost/phpmyadmin`.
2. Click the **Import** tab.
3. Choose `database/database.sql` and click **Import**.
4. This creates the `lab_borrowing` database with its tables and sample equipment.
